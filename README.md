# Kotoba Music v3.5.3

iPad向けの音階・口ドラム編集アプリです。

## 更新内容
- 口ドラムの無音・小さな背景音による余分な音符を低減。
- 発音中の振動や母音をまとめ、1発音を1音として解析。
- 短い高域ノイズはチッ、持続する高域ノイズはシャーに分類。
- ドン・タッの先頭にある破裂音がチッへ変わる誤判定を修正。

## 確認結果
提供された録音で「ドン・タッ・チッ・シャー」3セット、12音の分類が一致。
同じ録音の音量10%・30%・100%・180%、発音順の入れ替え、44.1kHz・48kHzで確認。
無音入力は0音。別の声、周囲の騒音、速い連打はまだ精度確認が必要です。
この結果は提供録音に対する検証で、一般的な認識率を示すものではありません。

## 更新方法
1. 旧版で必要に応じて「プロジェクト書出し」で作品を保存。
2. ZIPを展開し、GitHubリポジトリのindex.htmlを今回のindex.htmlへ置き換える。
3. 公開ページを再読み込みし、画面上部がv3.5.3になったことを確認。
4. ドラムのパートを選び、「ドラム入力」を「口ドラム」、「チッ／シャー判定」を「チッ優先」、「高域音の拾いやすさ」を「高」に設定して録音・変換。

録音データはこの更新ファイルには含めていません。

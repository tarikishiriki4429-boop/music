# Kotoba Music v3.8.2

iPad/Safari向けの単一HTML音楽エディタです。index.html をGitHub Pagesの公開ルートに置いて使用できます。

## 選択音のコピー・貼り付け
1. 音程バーを選択。複数の音なら「範囲選択」または「全音を選択」を使います。
2. 「選択音をコピー」を押します。
3. 「貼り付け位置（拍）」を指定して「貼り付け」を押します。曲の先頭は0拍です。
   コピー直後はフレーズの末尾が自動で設定されます。
   「選択音の位置」「選択音の後ろ」でも位置を指定できます。
4. 貼り付けた音はまとめて選択され、そのままドラッグで移動・音量変更できます。
   繰り返し貼り付けると、フレーズの長さだけ次の位置へ進みます。

- 単音・複数音・和音・ドラムに対応し、音程、間隔、長さ、各音の音量を保持します。
- 「選択音を後ろに複製」ならコピー操作なしでフレーズを繰り返せます。
- 他の楽器パートにも貼り付けできます。ドラムはドラム同士で貼り付けます。
- キーボード：⌘/Ctrl+Cでコピー、⌘/Ctrl+Vで貼り付け、⌘/Ctrl+Dで複製。
- 貼り付け・複製は「元に戻す」「やり直す」に対応。元の音符を上書きしません。
- コピー内容はこの画面を開いている間だけ保持します。貼り付けた音は自動保存・プロジェクト書出しの対象です。
- コピー対象は音符です。ボイスの元録音そのものは複製しません。
- 0〜200%の音量を、保存・再読込・プロジェクト取込後も保持するよう修正しました。

v3.8.1までの機能（広域認識、選択音から再生・録音、区間再変換、0.001拍の長さ編集、音量変更）を継続搭載しています。
ネットワークAPIを使用せず、コピー操作にクリップボードの許可は不要です。

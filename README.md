# Kotoba Music v1.6.5 — 録音・再生修正版

iPad Safariで使う、声をピアノ・ベース・ギター・ドラム・ヴァイオリンに変換する音楽アプリです。ボイスは元の声で再生します。録音・変換・保存は端末内で処理します。

## 更新方法

1. ZIPを解凍します。
2. 音楽アプリを公開しているGitHubリポジトリの同じ場所に、`index.html`、`sw.js`、`manifest.webmanifest`、**新しい `recorder-worklet.js`** の4ファイルをアップロードして置き換えます。
3. 公開ページをSafariで再読み込みします。画面上の **v1.6.5** を確認してください。
4. 旧版が出る場合は、オンラインで再読み込みし、一度Safariのタブとホーム画面のアプリを閉じてから開き直してください。

## 録音から再生まで

1. 「音のテスト」で出力を確認します。
2. ピアノなどのパートを選び、「声を録音」を押します。マイクを許可します。
3. 声を出して「録音停止」を押します。「変換完了: ○音」になるまで待ちます。
4. 「元の声を聴く」で録音を確認できます。「このパートだけ再生」で楽器に変換した音を聴けます。
5. 全体は画面上部の「再生」です。

「音符は0音」の場合、元音声は残っています。母音やハミングを少し長めに録音し、感度を調整して「録音を再変換」を押してください。無音録音を自動的に楽器音で埋める処理は行いません。

単独再生はM（ミュート）を無視しますが、音量0%では鳴りません。全体再生はMを尊重します。読み取り感度と音量は別設定です。

## v1.6.5：楽器ごとの特徴

- ギター：クリーンな撥弦音。弦の振動を模した合成、ピックの立ち上がり、胴の共鳴、弦の自然な減衰を追加。
- ピアノ：ハンマーの打撃、わずかにずれた複数の弦、先に消える高い倍音を表現。
- ベース：指で弾く短い高域と、後まで残る太い低音を組み合わせ。
- ヴァイオリン：弓で伸ばす音の立ち上がりと、胴の共鳴を反映した持続する倍音。音色のビブラートは約4セントの控えめな幅。
- ドラム：キックの低音と打撃、スネアの胴と響き線、ハイハットの不規則な金属的倍音を分離して合成。

更新後は保存済みの音符をそのまま再生すると、新しい音色になります。音色を変えるための録音・再変換は不要です。声の震え補正も引き続き使えます。

すべて端末内の合成音です。生楽器の録音サンプルを使った音源ではなく、本物と同じ音質を保証するものではありません。コード・再生予約・停止処理と、ギター波形の有限性、減衰、減衰区間での音程を44.1kHz/48kHzで検証しました。実機での試聴は未実施です。

## v1.6.4：声の震え補正

楽器に変換するとき、声の震えを別の音符として拾いすぎないようにしました。元の録音音声自体を加工する機能ではありません。

1. 「声の震え補正」を「強め」にします（初期設定）。
2. 保存済みの声は「録音を再変換」を押します。
3. 「このパートだけ再生」で確認します。

「強め」は短い音程の揺れと音量の震えによる再発音を抑制します。「標準」は細かなメロディーを残しやすく、「オフ」は以前の一音ずつの検出に近い設定です。意図した速い半音移動やトリルまでまとまる場合は「標準」または「オフ」を選んで再変換してください。

音程変化の継続を確認してから別の音に分け、短い揺れで音の長さが欠ける問題も修正しました。震え補正の選択はこの端末に保存します。

合成音声で、毎秒4・5・7回の音程の揺れ（上下0.7／1.1半音）と音量の揺れを重ねた6条件が、一つの音符になることを確認しました。同音連打・半音移動・オクターブ跳躍の既存テストも通過しています。実際のユーザーの声とiPadでの確認は未実施です。

## v1.6.3：一音ずつの認識

- 音程の周期判定を、正規化した差分で判定する方式へ変更。倍音を含む声で音程がずれる問題を抑制。
- 音の区切りを約10ミリ秒ごとに調べ、短い休符と音量の落ち込みからの再発音を検出。
- 同じ高さの音の連続を、息の切れ目・再発音に応じて別の音符として扱います。
- オクターブ跳躍を強制的に低い音へ変更する処理を廃止。
- 一瞬の揺れで音符が増えすぎないよう、音程変化の継続を確認。
- 前の音が次の音に重なりすぎないよう音の長さを調整。

更新後、保存済みの録音は「録音を再変換」で新しい判定を使えます。まず「声のリズムのまま」「音程補正：自然」で試してください。「タ・タ・タ」のように一音ごとに軽く区切ると、同じ高さの連続音を認識しやすくなります。
音量や音程の変化がない一本の伸ばした声から、意図した音符の数を推測することはできません。

合成音声で、44.1kHz／48kHzの音階、半音移動、同音連打、オクターブ跳躍、音をつなげたフレーズ、ビブラート、雑音のテストを通過しました。実際の声とiPadマイクを使った認識精度は未検証です。

## v1.6.2から引き継いだ修正

- 録音をPCMで直接取得し、録音ファイルの形式・解読処理に依存する再生失敗を回避。
- マイク用と再生用の音声エンジンを分離し、録音停止後にマイクと録音用エンジンを解放。
- 再生エンジン停止・中断時の復帰とエラー表示を追加。
- 元録音を端末内に保存し、再起動後も復元。プロジェクト保存にも元音声を含めます。
- 変換音が0個、音量が0%、全パートがミュートなど、無音になる状況を表示。
- 停止ボタンで楽器・元音声・テスト音を停止。
- 同じ音を2〜3オクターブ低く読み取る誤検出と、ヴァイオリンの検出範囲を修正。
- 短い音の音量カーブを修正。長い録音の変換中も画面が応答できるように処理を分割。
- ボイス録音の開始位置を反映し、ボイスの長さを含めたWAVを書き出し。
- オンラインでは新しいページを優先し、オフラインでは同じ版のキャッシュを利用。

## 保存と利用上の注意

録音中は画面を開いたままにしてください。画面を離れると録音を停止します。最大5分です。
旧版のプロジェクトには元音声が保存されていなかったため、既に失われた旧録音は復元できません。音符は旧形式から読み込めます。
端末のサイトデータを消すと自動保存も消えます。大切な曲は「プロジェクト保存」でJSONファイルとして残してください。
マイク利用はHTTPS（または開発用localhost）が必要です。ZIP内のHTMLをファイルとして直接開く方法では利用できません。

## 検証範囲

コードの構文、合成した音声の音程変換、録音データの受け渡しを検証しています。再生予約・停止・復元・保存は音声APIと保存APIを模擬したテストで確認しました。ブラウザで実際に音が出ることを確認したテストではありません。実機iPad Safariでのスピーカー出力とマイクは、この修正版を入れて確認してください。

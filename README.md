# Kotoba Music v3.8.1

iPad/Safari向けの単一HTML音楽エディタです。`index.html` をGitHub Pagesの公開ルートに置いて使用できます。

## v3.8.1 changes
- 選択した音ごとの音量調整を追加
- 1音選択・複数選択の両方に対応
- 選択音の音量を 0〜200% で変更可能
- 複数選択時は選択中の全音へ同じ音量を一括適用
- 選択音ごとに音量差がある場合は範囲表示
- 再生・試聴・WAV書き出しにも各音の音量を反映

v3.8.0 の広域音程認識、大ジャンプ追従、15/20ms短音解析、選択音から再生・録音なども継続搭載しています。

ネットワークAPIは使用しません。

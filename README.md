# Kotoba Music v3.1

iPadのSafari / GitHub Pages向け。声を録音し、ピアノ・ベース・ギター・ヴァイオリン・ドラムの音符へ変換して曲を作る、無料のブラウザアプリです。音程解析・録音・保存に外部AIや有料APIは使いません。

## v3.1：速い音階・高低への跳躍

初期設定は「音程の追従＝高速追従」「最短音長＝30ms」です。既存の録音は「録音を再変換」で新しい処理を適用できます。

- 5ms間隔で解析し、短い解析窓と低音向けの長い解析窓を併用します。
- 新しい音の確定待ちを短縮。オクターブ移動の抑制を弱め、明確な新しい音へ切り替えます。
- 音程と信頼度が安定した短音を、中間音除去から保護します。短い音をすべて消す処理にはしません。
- 揺れや中間音が増える場合は「安定優先（従来）」へ戻せます。細かい旋律では、最短音長を50ms以上に上げすぎないでください。
- 特に低い音は周期が長いため、高音と同じ速さで区切れない場合があります。実際の歌声・息・子音が混じる場合の認識は完全ではありません。

## まず使う

1. 上の楽器名を押して編集するパートを選びます。音符編集は必ず楽器項目のすぐ下に表示されます。
2. 「声を録音」を押し、1つのメロディーを歌います。もう一度押すと停止。最大録音時間は1 / 3 / 5分です。
3. 録音停止後に変換します。黄色の音符は判定に迷った箇所なので、元の声と聴き比べてください。
4. 音符を上下にドラッグすると音程、左右で開始位置、右端で長さを変えられます。空いているマスのダブルタップでも追加できます。
5. 「▶ このパート」で選んだパートを試聴。「S」はそのパートだけ再生、「M」はミュートです。
6. 「音量・保存・音の確認」を開くと、全体音量、楽器ブースト、プロジェクト書出し、WAV書出しがあります。

## 精度の調整

- 基本設定：感度4倍、認識音域「精度優先」、高速追従、震え抑制「標準」、中間音除去「標準」、最短音長30ms、量子化「声のまま」。
- 余計な中間音が残るとき：中間音除去を「強」にして「録音を再変換」。
- 意図した速い旋律が消えるとき：中間音除去を「弱」またはOFF、震え抑制を弱め、最短音長を30msにします。
- 小さい声の音を拾えないとき：読み取り感度を上げます。周囲のノイズも増えるため、静かな場所で試してください。
- 入力メーター／モニターブーストは表示とモニター用です。原音は歪ませずに保持します。録音モニターはイヤホンで使ってください。
- 「声のまま」では編集単位に自動的に丸めません。8分・16分・32分を選んだときだけ量子化します。
- 解析中は中止できます。中止しても録音と変換前の音符は残ります。

## v3.0の改良

- v2.6の5分録音、モニター、音声取込、ダブルタップ追加、ピンチ拡大、iPad互換プレイヤーを復元。
- v2.7の独立した中間音除去を統合。前後に十分な長さの音がある場合に短い移行音を統合。
- 倍音・オクターブ候補を前後フレームから選択。高音で周期の整数倍を誤採用する問題を修正。
- 半音の変化を保持しながら揺れを抑える補正。連打・休符を保持。
- ノイズゲート、解析窓とタイミング、録音開始位置、量子化の重なりを修正。
- 解析と曲の生成をWorkerへ移し、進捗表示と中止に対応。
- 音符削除などを戻せる履歴。音量・ミュート・ソロも保存。
- 録音を含む自動保存と復元。プロジェクトJSONにも録音を含めます。
- 80拍を超える曲も表示・再生・書出し可能。元声の長さも書出しに含めます。
- 再生・試聴・WAV書出しの音作りを統一。WAVは44.1kHz・16bit・モノラル。音量差を消す自動正規化を廃止し、過大出力を緩やかに抑制。
- 原音ボイス再生時に変換音が二重に重なる問題を修正。

## 保存と旧版からの更新

- 更新前に旧版からプロジェクトを書き出してバックアップしてください。
- 同じGitHub PagesのURLで使っていた場合、v2.6 / v2.7の旧音符データを読み込めます。両方の旧データがある場合はv2.7側を優先します。
- 旧版が保存していなかった録音は復元できません。v3.0からは録音も自動保存し、JSON書出しにも含めます。
- 保存先は使用中のSafariのサイトデータです。履歴削除・サイトデータ消去に備え、プロジェクト書出しでバックアップしてください。
- WAVは聴くための音声、プロジェクトJSONは編集を再開するためのデータです。
- ローカルHTMLでマイクが使えない場合は音声ファイル取り込みを使用してください。直接録音にはHTTPSで開いたGitHub Pages版を使います。
- 本版はネットワークへ音声を送信しません。初回のページ読込には通信が必要です。通信不要での再起動は保証していません。

## 検証の範囲

合成音の単音・倍音・半音移動・短い移行音・短音を保持するOFF設定・ビブラート・同音再発音・小音量と雑音・無音・雑音のみ・オクターブ移動・複数サンプルレートを検証。
ブラウザで追加、削除、元に戻す、やり直す、ドラッグ、ダブルクリック、Worker変換、録音開始位置、元タイミング、録音復元、録音入りJSONの書出し／読込、WAV書出し、互換再生、iPad相当の縦横幅とスマートフォン幅を検証。

実際のiPadのマイク録音・Safariの音声経路は実機確認が必要です。音程変換は単旋律向けで、歌声の息成分・子音・しゃくり・環境雑音によって誤認する場合があります。和音を複数の楽器へ分離する機能はありません。楽器音は内蔵の合成音です。

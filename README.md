# Kotoba Music v3.17.0

index.htmlをGitHub Pagesなどで公開して使用できます。

## ファイルから取り込む
「音楽ファイルを開く」でMP3/WAV/M4Aなどを選びます（形式対応は端末によります・100MB以下）。選択中と同じ種類の新しいパートに入ります。元の音声を加工したい場合はボイスパートを選んでから取り込んでください。元のパートは残ります。

## 譜面
「選択パートの五線譜を見る」で音程確認用の参考譜を表示します。横位置は拍、数字は長さ（拍）です。通常のリズム譜表記ではありません。BPMは手動設定。旋律1本の解析向けで、完成曲の楽器分離や和音採譜は行いません。ドラムは音程バー表示を使います。

## 書き出し
WAVは再生対象の曲を音声として保存します。MIDIは音符・BPM・楽器を保存します。M／Sの対象を反映します。MIDIには元音声・声の加工は含まれません。旋律パートは15本までです。

シンセサイザーを楽器一覧に追加しました。持続する明るい電子音で、音程バー編集・試聴・曲再生・WAV・MIDI書き出しに対応します。既存のプロジェクトでは楽器一覧からシンセサイザーを選んで追加してください。MIDIはGM Lead 2（sawtooth）を指定します。MIDI再生時の音色は再生ソフトによって異なります。

シンセの音声生成・持続・立ち上がりと終端を検証し、既存楽器の出力が変わらないことも確認しました。
検証：スクリプト構文、MIDI構造・チャンネル・音符時刻、参考譜生成を確認。今回の環境ではブラウザが起動できず、実ブラウザの取込〜保存とiPad実機は未検証です。

## v3.11.0 音のつながり
シンセ／ヴァイオリンの単旋律を、位相が続くレガートで再生します。編集画面でON/OFF、つなぐ短い隙間（0/30/60/100ms）、音程グライド（0/25/60/120ms）を指定できます。曲再生とWAVに反映されます。音符自体の位置・長さは変えません。MIDIは元の音符を保存し、この合成音のつながりを含みません。
選択した音がある場合「音のつながりを試聴」は選択音を、選択なしではそのパート全体を試聴します。
既存プロジェクトにもシンセ／ヴァイオリンはレガート初期ON、シンセは25msグライド、ヴァイオリンはグライドOFFを適用します。和音のあるパート・長い休符・認識した弾き直しは独立音の処理で保持します。
検証：連続音の短い隙間に音が出ること、始終端、グライドが曲長を変えないこと、OFF時・和音・休符・弾き直しの出力一致、既存楽器の音声出力一致、スクリプト構文を確認。録音の音程認識エンジンは変更していません。音程認識の精度向上はこの更新では検証・実装していません。iPad実機・ブラウザUIの通し確認は未実施です。

## v3.12.0 全パートでタイミング編集
トラック一覧の下に全パートの共通タイムラインを追加しました。同じ拍目盛りでピアノ・ドラムなどを見ながら、音をタップして選択、左右ドラッグで開始時刻、右端で長さを編集します。音程は従来の編集画面で変更できます。
「移動の刻み」は自由（0.001拍）、32分、16分、8分、1拍。「選択パート全体を早く／遅く」は指定の刻みだけ全音を動かします。先頭が0拍より前に出ないように、音の間隔を保って制限します。複数パートを一度に選択する機能はありません。
選択音の開始・長さは数字でも入力できます。全体再生、選択音から再生、停止、拡大縮小、再生位置表示に対応します。録音・解析・曲作成中は編集を止めます。元に戻す／保存は既存の仕組みを使用します。画面の空き部分から横スクロールしてください。
検証：イベント処理を模した環境で別パートの選択と移動、長さ変更、ドラッグ中止の復元、全体移動の間隔保持、数値境界、解析中の編集禁止を確認しました。構文と音声エンジンが前版と同一であることも確認。iPad実機と実ブラウザUIでの通し確認は未実施です。

## v3.13.0 音追加・上下左右編集・拡大縮小
全パート画面を音程マス付きに変更しました。旋律パートはMIDI 0〜127（C−1〜G9）の全音域を縦スクロールできます。ドラムは4音種の専用行です。空きマスのダブルタップ／ダブルクリックでその音程・拍に音を追加、音の上下左右ドラッグで音程・タイミング、右端で長さを変更します。
「移動の刻み」は追加位置と左右移動に、「長さの刻み」は右端ドラッグに使用します。数値で細かく編集することもできます。極短い音は触りやすい最小幅で表示されますが、保存する長さは数値どおりです。音程・開始・長さの欄と従来の編集画面は同じデータを扱います。
横拡大と縦拡大を個別に指定できます。共通画面の2本指ピンチで両方を調整します。横拡大50〜400%、縦拡大60〜250%。ピンチ解除後の450msは誤追加を防止します。拡大率を変えても表示中の場所を保ち、音程表示は横スクロール中も固定します。「高い音／低い音」で各パートの表示音域を移動し、「選択音へ」で音を見つけられます。
ドラッグ中止で元の音程・位置・長さを復元し、録音／解析／曲作成中の編集を禁止します。従来の単一パート編集では全MIDI音域を初期設定にし、表示範囲外へ動かすと広域表示に切り替えます。拡大縮小の中心維持と端でのスクロールも改善しました。
検証：ヘッドレスChromiumでタッチのダブルタップによる1音だけの追加、拡大・スクロール後の位置一致、低音と最高音、ドラムの行対応、従来ピアノロールの追加、上下左右ドラッグ、2本指タッチによるピンチ、タッチ中止の復元、右端の長さ変更、元に戻す／やり直す、実行時エラーなしを確認しました。音声エンジンはv3.12.0と同一です。iPad実機のSafariでは未確認です。

## v3.14.0 ボイスの通常録音・波形・トリミング
ボイスを選ぶと通常録音と波形編集が初期モードになります。自動で音符に分割しません。録音・ファイル取込後、元録音の波形を表示します。波形をドラッグするか開始／終了の秒数を入力し、「トリミングを適用」で選択範囲だけを残して再生・WAVに反映します。5ms以上の範囲を指定してください。元録音・保存ファイルの音声自体は保持し、トリミングを戻す／元に戻す／やり直すが使えます。トリミングした声はそのパートの録音開始位置から鳴ります。全パート画面にも声の波形クリップを表示します。パート全体を早く／遅くする操作で録音開始位置を移動できます。
雑音フィルター（OFF／弱／標準／強）は録音全体に適用します。低域の振動、高域のざらつき、低レベルの背景音を帯域制限と滑らかなゲートで抑えます。全ての雑音を声から分離するものではなく、強い設定では声の質感も変わります。波形は元録音を表示し、フィルターは再生・WAVに適用します。「元の録音を聴く」は未加工の音です。
従来の音程バーによる声編集は編集方法を「音程バー編集」に切り替えて利用できます。既存の音符データは通常モードに切り替えるだけでは削除しません。新しく通常録音で全体を録り直した場合は以前の音符をクリアします。通常録音モードの声はMIDIに含めず、WAVで書き出してください。
「このパートを再生」を上の全体再生と共通画面の全体再生の隣に配置しました。選択パートだけを鳴らし、M／Sを一時変更しません。選択パートがMでも試聴できます。
検証：ヘッドレスChromiumで通常録音としての音声ファイル取込（音符に分割しない）、波形と共通クリップ、非破壊トリミング、Worker経由のWAV長さと切り出した音程、単独再生、フィルター設定保存、波形ドラッグ、トリミングの元に戻す／やり直す、音程バー編集への切替を確認。合成音で背景音抑制と声成分保持、他楽器の出力一致も確認しました。iPad実機でのマイク録音とSafari操作は未確認です。

## v3.15.0 ボイスの位置・途中録音を分かりやすく
波形編集の近くに「声を曲のどこで鳴らす？」と「どこから録音を再開する？」を追加しました。
声の開始位置は曲の拍／秒のどちらでも指定でき、「少し早く／遅く」「曲の先頭へ」で動かせます。共通画面の声の波形クリップは左右ドラッグで移動できます。録音する位置と声全体の開始位置は別々に表示します。
「波形の操作」を「録音する位置を選ぶ」にすると、残している範囲をタップ／ドラッグして青い録音位置を指定できます。「ここから録音」は前後を残す録音方法と開始位置を自動設定し、「最後に続きを録音」はトリミング後の声の終端から録り足します。停止は通常の声録音ボタンまたは上部停止ボタン。録音開始前カウント等の設定は従来どおりです。秒／拍／小節の位置表示は現在のBPMに基づきます。
トリミングした声を途中から録り直すとき、元の未トリミング部分が戻ったり、位置がずれたりしないよう、切り出した音声を基準に接続します。音声エンジンはv3.14.0と同一です。
検証：ヘッドレスChromiumで秒と拍の相互入力、少し移動、波形タップによる録音位置、途中／続き録音の開始と保持モード設定、声のクリップ移動と元に戻すを確認。合成PCMによる録音取り込み・接続で、トリミング後の前後区間保持と終端への追記も確認済み。実マイクの録音開始自体とiPad実機は未確認です。

## v3.17.0 通常録音のボイス明瞭度
ボイスの波形編集に「声の明瞭さ：原音寄り／クリア（推奨）／くっきり」を追加しました。録音前にも選べ、ファイル取込で設定を引き継ぎます。元録音は変更せず、通常録音モードの声の再生・WAVに反映します。「元の録音を聴く」で未加工の録音と比較できます。まず「クリア」と雑音フィルター「弱」で試してください。
雑音フィルターを見直し、弱い声を過度に切り落とさないよう、背景レベルと大きい声のレベルを基準に抑制量を制限しました。高域の帯域制限を見直して子音域を保ちやすくし、明瞭さ設定では低い濁りを軽く抑えて3.2kHz付近の存在感を持ち上げます。原音寄り＋雑音OFFではこれらのEQと雑音抑制を使いません。トリミング端の短いフェードは維持します。
通常録音の声を含むミックスでは、音量ブーストで波形を強く潰す従来の処理を先読みピーク制御に変更しました。音程・長さを変えずに出力の歪みを抑えます。原音自体のクリッピングや強い反響、声と重なる雑音を完全に復元・分離する機能ではありません。音程バーによる声変換の処理は従来どおりです。
検証：合成の大音量正弦波で歪み成分を旧版比90%以上抑制、出力長さ一致、ピーク上限、強い雑音設定下での弱い声保持、明瞭度設定の帯域変化、高域雑音抑制、楽器のみの出力一致を確認しました。Chromiumでは明瞭度の事前選択と設定引継ぎ、Worker経由WAVの長さ・ピーク、実行時エラーなしを確認。実際のユーザー録音での聴感とiPad実機は未確認です。

ヴァイオリン：胴の共鳴を意識した倍音・弓の摩擦成分・遅れて入るビブラート。シンセ：少しずらした2音源と時間で変化する明るさ。どちらも単音／和音／レガートに共通の音源を使用。ベース：弾弦位置による倍音と減衰、控えめな弾く音。ドラム：キックの低音と打撃、スネアの胴とスナッピー、ハイハットの金属成分を個別に合成。開いたハイハットは次のハイハットで減衰。ドラムは短いバーでも打撃後の余韻を再生します。全楽器の重なりで音割れを抑える出力制御。

# Kotoba Music v3.7.0

## 声の揺れをまとめる
「録音 → 音符」の読み取り設定にOFF／弱／標準／強を追加。
音量、音程の信頼度、前後の音程から中心となる音を選び、弱い短い揺れを近くの強い音につなぎます。
伸ばす音には強、速い旋律・装飾音には弱またはOFFを試してください。
意図した短い音も強設定では変わる可能性があるため、区間ごとの適用に対応しています。
ヴァイオリンの声入力でも低い声を解析できるよう、自動音域の下限を50Hzに拡張。

## 区間ごとの設定反映
1. 音程バーを選択（複数選択可）。
2. 「選択音から区間を指定」を押す。必要なら開始・終了（拍）を調整。
3. フィルター、安定化、最短音長などを設定。
4. 「この区間に設定を反映」を押す。
前後の音符と元の録音は保持します。複数選択の場合は最初から最後までの間も対象です。
元の録音がない手動追加音は直接編集してください。
「全体を再変換」は全区間に現在の設定を適用し直します。

## 続き・区間録音
- 「続きから録音」：選択パートの音符・録音の末尾から追加。カウントダウンと伴奏設定を利用できます。
- 開始（拍）と終了（拍）を入力して録音：終了位置で自動停止、その区間だけ録り直し。
- 終了が空欄の場合は手動停止または最大録音時間で停止。
- 「指定位置から録音（前後を残す）」なら終了が空欄でも前後を保持。
- 「全体を録り直す」で終了が空欄の場合は従来の録り直し動作。
- 手動で早めに停止した場合は、実際に録れた区間だけを置き換えます。
- 元の音符が区間境界をまたぐ場合は、区間外の部分を残します。
- 伴奏使用時はイヤホン推奨。iPad側のマイク・再生遅延による位置ずれは手動調整してください。

## 既存機能
複数音の移動・削除、最小0.001拍の長さ調整、長さを半分、ヴァイオリンの持続音を維持。

## 検証
提供音声を同じ条件（ピアノ／高速／安定化2／最短30ms）で解析。
フィルターOFF：81音、うち80ms未満54音。
標準：57音、うち80ms未満16音。強：53音、うち80ms未満15音。
これは断片化の減少を示す比較で、意図した音程の正解率ではありません。スクリーンショットと解析設定が同じとは限りません。
合成音で半音移動・大きな跳躍を保持。弱い断片の結合、休符、連打保持を確認。
模擬音声データで区間の前後保持、区間だけの再変換、終了位置による録音時間制限を確認。
iPad実機の録音・画面操作は未確認です。

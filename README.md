# Kotoba Music v3.6.1

## 音程バーの複数選択
- トラックパッド／マウス：空きマスを押したままドラッグして範囲選択。
- Shift、⌘、Ctrlを押しながらバーをクリック：追加選択・選択解除。
- iPadのタッチ：範囲選択をONにして空きマスをドラッグ。
- 選択したバーをドラッグ：複数の音を間隔を保って上下左右に移動。
- 選択したバーの右端をドラッグ：選択音の長さを一緒に変更。
- 選択音を削除ボタン、Delete、Backspace：選択した音だけ削除。
- 全音を選択、⌘A／Ctrl+A：選択パートの全音を選択。
- 矢印：編集単位で移動、上下は半音。Shift＋矢印は4単位。
- 選択解除、Escape：選択解除。範囲選択OFFで通常のタッチスクロール。
- 複数選択中は個別音の数値編集欄を無効にし、ドラッグで一括編集。

## 録音
- 録音前カウント：なし／4拍／8拍。現在のBPMに従います。
- カウント音ON／OFF。OFFでも数字を表示。
- カウントやマイク準備中に録音ボタンを再度押すと開始をキャンセル。
- 録音中の伴奏：OFF／楽器パート／他の全パート／ボーカルのみ。
- 録音するパート自身は伴奏から除外。M／S、パート音量に従います。
- 録音開始（拍）に合わせて伴奏も途中から再生。停止時に伴奏も停止。
- 伴奏を録音へ混入させないためイヤホン推奨。
- 元の声を直接聞く録音中モニターは、伴奏と別の設定です。
- ファイル取り込みではカウントダウンは使用しません。

## v3.6.1：短い音とヴァイオリン
- 長さの刻みを移動の編集単位から分離。0.001拍〜16分単位で調整。
- 音の長さは最小0.001拍まで。長さ（拍）の数値入力でも指定可能。
- 長さを半分ボタンで選択した音をまとめて短縮。
- 移動の編集単位に64分・128分・0.01拍・0.001拍を追加。
- 新規追加音の長さを編集単位に合わせ、8分音符の下限を解除。
- 試聴時に短い音を強制的に長くする処理を削除。短い音の余韻も短縮。
- 短いバーの一部を移動用に残し、全体が長さ変更用になる問題を修正。
- 単発のオクターブ誤検出を補正。ヴァイオリンは声の揺れや小さな途切れによる分割を低減。
- ヴァイオリンに倍音、緩やかなビブラート、持続中の音量変化、最大0.24秒の余韻を追加。

合成したテスト音で、揺れのある1.5秒の音が17分割から1音へ改善。
160msごとの半音・音程跳躍の系列も一致。実際の声全般の認識率を保証する結果ではありません。
ヴァイオリン音は合成音で、生楽器の収録音ではありません。

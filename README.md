# Kotoba Music v2.3

声を録音して、ピアノ・ベース・ギター・ヴァイオリン等の音符へ変換し、iPadで編集する試作アプリです。

## v2.3 の主な変更

- ボイス以外の楽器専用「楽器ブースト」を追加（100〜400%、初期250%）。
- ピアノ / ベース / ギター / ヴァイオリン / ドラムをボイスより埋もれにくいバランスへ調整。
- Web Audio再生、iPad互換再生、WAV書き出しのすべてで楽器ブーストを反映。
- 「録音中モニター」を追加（OFF / 25 / 50 / 75 / 100%）。イヤホン推奨。
- 「録音後の元声 自動再生」を追加し、初期ONに設定。
- これまでの音程精度改善、C−1〜G9編集、ピンチズーム、入力ブースト、震え抑制を維持。

# Kotoba Music v2.0

iPad / Safari / GitHub Pages向けの声→音符編集アプリです。

## v2.0の主な変更
- 音程編集エリアを右側配置から廃止
- ピアノ / ベース / ギター / ボイスなどのトラック欄の**下**へピアノロールを全幅表示
- iPadで2本指ピンチイン / ピンチアウトして50〜300%ズーム
- 1本指の音符ドラッグと2本指ズームを分離
- 「拡大編集」で画面ほぼ全体をピアノロールに使用
- 全体音量ブースト 100〜400%
- マイク入力ブースト 1〜64倍
- 読み取り感度 1〜128倍
- 震え抑制 OFF〜LOCK（最強）
- 手動音域 MIDI 0〜127（C−1〜G9）

## GitHub Pages
ZIPを展開し、中身をリポジトリのルートへアップロードしてください。
Settings → Pages → Deploy from a branch → main → /(root) を選びます。

マイクはHTTPSのGitHub Pages上で使ってください。Safariでマイク許可が必要です。

# Kotoba Music v1.6

iPad Safari向けの「声→楽器」音楽制作アプリ試作版です。

主な変更:
- 最大5分録音
- ピアノ/ベース/ギター/ドラム/ヴァイオリンの音色強化
- ヴァイオリン新規追加
- 音程検出を複数フレーム中央値で安定化
- オクターブ飛び補正
- 読み取り感度 1〜32倍
- 音程補正: そのまま/自然/強め
- パート単独再生、ミュート、0〜400%音量
- 32分音符編集
- WAV書き出し
- PWAキャッシュ対応

## iPadで使うとき
マイク利用にはHTTPSが必要です。GitHub PagesなどHTTPSで公開してSafariから開いてください。
初回表示後はPWAキャッシュによりオフライン利用できますが、iOSの仕様によりマイク権限やキャッシュが再確認される場合があります。

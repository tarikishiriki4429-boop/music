# Kotoba Music v3.8.0

iPad/Safari向けの単一HTML音楽エディタです。`index.html` をGitHub Pagesの公開ルートに置いて使用できます。

## v3.8.0 changes
- ボイス / ベース / ギター / ヴァイオリンの自動認識音域を拡張
- 手動の低音優先を 25Hz〜1.2kHz、高音優先を 70Hz〜4.2kHz、超広域を 25Hz〜4.2kHz に拡張
- 大きな音程ジャンプを震え補正が潰しにくいよう改善
- 低域での1オクターブ下誤認を抑制
- 15ms / 20ms の最短音長設定を追加
- 選択した音から再生、選択した音から録音、選択区間だけ再変換、0.001拍編集は継続搭載

ネットワークAPIは使用しません。

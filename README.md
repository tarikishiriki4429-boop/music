# Kotoba Music v2.2

声を録音して、ピアノ・ベース・ギター・ヴァイオリン等の音符へ変換し、iPadで編集する試作アプリです。

## v2.2 の主な変更

- 音程検出を改良し、倍音を別オクターブとして誤認しにくくしました。
- 録音認識用の音域と、編集・再生可能な音域を分離しました。
- 初期設定は「精度優先 50Hz〜2.2kHz」。編集画面は従来どおり C−1〜G9 に対応します。
- 入力ブーストの推奨値を2倍へ変更。上げすぎによる波形の歪みを抑えます。
- 録音経路に低域ノイズ除去・高域ノイズ抑制を追加しました。
- ベース音色の1オクターブ下の副成分を削除し、表示音程と聞こえる中心音程を一致させました。
- C4 / A4=440Hz / C5 の基準音ボタンを追加しました。
- ピンチズーム、拡大編集、iPad互換再生はそのまま利用できます。

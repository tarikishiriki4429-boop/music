# Kotoba Music v2.1

iPad / Safari向けの音声出力修正版です。

## v2.1 の主な変更
- iPadでは「iPad互換再生」を標準使用
- 曲を内部でWAV化し、HTML audioプレイヤーから再生
- 「音のテスト」もWeb Audioに依存しない方式へ変更
- 元の声も互換プレイヤーで再生
- マイク入力ブーストを実際の録音信号へ適用
- 入力ブースト最大256倍
- 既存のピンチズーム、広音域、震え抑制を維持

## GitHub Pages
このフォルダの中身をリポジトリ直下へアップロードしてください。
`index.html` / `app.js` / `styles.css` は必須です。

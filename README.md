# Kotoba Music v3.3.0

iPad / Safari 向けの録音→音階・ドラム変換アプリです。

## v3.3.0 の主な改善
- 速い音階で本物の短音を消しにくい中間音除去へ変更
- 半音・全音の高速移動を「震え」と誤認しにくい近接音統合
- 大きな高低音ジャンプの高速追従を維持
- 弱い入力に追従する自動ノイズゲート
- ドラムのアタック検出を高感度化（キック / スネア / ハイハット候補）
- PCMバックアップを細かく取得して録音復元を強化
- Worker解析に失敗した場合、互換解析へ自動フォールバック
- 既定の読み取り感度を8倍へ変更

## GitHub Pages
リポジトリ直下の `index.html` と `README.md` をこのZIP内のファイルで置き換えてください。
Pages公開URLをSafariで開くと、マイク録音が利用できます。

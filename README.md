# Kotoba Music v3.5.1

iPad/Safari向けのオフライン音階・口ドラム変換アプリです。

## v3.5.1
- 口ドラムの「チッ」を「シャー」と誤認しにくいよう判定を変更
- 総発音時間ではなく、3.2kHz以上の高域ノイズが実際に持続した時間を重視
- 「チッ」の後に母音や残響が長く続いてもシャーへ昇格しにくい処理
- 次の打音までを上限にして、前の残響をシャー判定へ混ぜにくくした
- 「チッ／シャー判定」設定を追加
  - チッ優先（推奨）
  - 標準
  - シャー優先

GitHub Pagesでは `index.html` をリポジトリ直下に置いてください。

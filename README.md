# Kotoba Music v2.6

声を録音して、ピアノ・ベース・ギター・ヴァイオリン等の音符へ変換し、iPadで編集するGitHub Pages向けアプリです。

## v2.6 の主な変更

- 音程変換エンジンを全面的に更新。
- YIN系の基音推定に、倍音・サブハーモニック判定を追加。
- 1オクターブ上 / 下へ飛ぶ誤認を、スペクトル上の基音証拠と前後フレーム追跡で補正。
- 瞬間的な外れ値を1〜2フレーム単位で補修。
- ビブラートや声の震えは、実際の音程変化を潰しすぎない狭い中央値処理へ変更。
- 無音・息・環境ノイズを動的ノイズゲートで除外。
- 同じ音を連続で歌った場合も、音量の落ち込みと再アタックから別音符として分けやすくしました。
- 高音認識では解析サンプルレートを引き上げ、低音・高音それぞれの認識モードを維持。
- 1 / 3 / 5分録音、録音モニター、元声自動再生、入力ブースト、震え抑制、ダブルタップ追加、ピンチズーム等はそのままです。

## 精度を出しやすい録音

- まずは「読み取り感度 4倍」「入力ブースト 2倍」「震え抑制 標準」「認識音域 精度優先」を推奨。
- できるだけ1音ずつ、母音をはっきり歌うと安定します。
- ブーストを上げすぎると波形が潰れて逆に誤認しやすくなるため、入力レベルが十分なら2〜4倍程度が適しています。
- この変換は単旋律向けです。複数人の声、和音、伴奏が同時に入る録音は完全分離できません。

## GitHub Pages

`Settings > Pages > Deploy from a branch > main > /(root)` で公開できます。

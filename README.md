# Kotoba Music v2.5

声を録音して、ピアノ・ベース・ギター・ヴァイオリン等の音符へ変換し、iPadで編集する試作アプリです。

## v2.5 の主な変更

- 最大録音時間を **1分 / 3分 / 5分** から選択可能にしました。初期値は5分です。
- 録音中に `経過時間 / 最大時間` を表示します。
- 最大時間に達すると自動停止して、そのまま音程解析へ進みます。
- 以前の録音タイマーが次の録音を誤って止める問題を防ぐため、停止時にタイマーを確実に解除します。
- 長い録音の音程解析中は処理を小分けにして、画面が固まりにくいようにしました。
- v2.3までの楽器ブースト、録音モニター、録音後の元声自動再生、音程精度改善、C−1〜G9編集、ピンチズーム、入力ブースト、震え抑制を維持しています。

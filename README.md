# Kotoba Music v2.7

iPad / browser向けの声→音符変換・ピアノロール編集アプリです。

## v2.7
- 「震え抑制」とは別に「中間音除去」フィルターを追加
- 中間音除去: OFF / 弱 / 標準 / 強
- ド→ド♯→レのような短い移行音を前後の音程から判定して除去
- 同じ音に挟まれた一瞬の外れ音も統合
- 強度ごとに除去する最短音長・許容半音幅・反復回数を調整
- 初期値は「標準」
- 既存の録音は「録音を再変換」で新フィルターを適用可能

GitHub Pagesでは `index.html` と `README.md` をリポジトリ直下に置いてください。

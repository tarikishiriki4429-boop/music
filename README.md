# Kotoba Music v1.8

iPad / Safari / GitHub Pages向けの声→音符編集アプリです。

## v1.8の主な変更
- iPad SafariでAudioContextをユーザー操作時に確実に再開する処理を追加
- 「♪ 音のテスト」を追加
- 全体音量ブースト 100〜400%
- マイク入力ブースト 1〜64倍
- 読み取り感度 1〜128倍
- 震え抑制 OFF〜LOCK（最強）
- ピアノロール 50〜300%ズーム
- 「拡大編集」モード
- 空白を指でスクロールし、音符を掴んだ時だけドラッグ編集
- 手動音域 MIDI 0〜127（C−1〜G9）

## GitHub Pages
このZIPを展開し、中身をリポジトリのルートへアップロードしてください。
Settings → Pages → Deploy from a branch → main → /(root) を選びます。

マイクはHTTPS上のGitHub Pagesで使用してください。Safariでマイク許可が必要です。
